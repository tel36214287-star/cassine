
# 🎰 Cassino Virtual - Caça-Níquel Interativo
or
The slot machine with jackpot, brit until,possible!

Bem-vindo ao **Cassino Virtual**, um projeto de **caça-níquel online** desenvolvido em **HTML, CSS e JavaScript**. Este projeto foi criado **para fins educativos**, permitindo que iniciantes e entusiastas da programação aprendam conceitos de **manipulação de DOM, lógica de jogos e interatividade web**, enquanto se divertem simulando um cassino.

> ⚠️ Este projeto **não envolve dinheiro real** e serve apenas como ferramenta de aprendizado e prática de programação.

---

## 🕹 Funcionalidades Principais

- **3 rolos (reels)** com símbolos aleatórios.
- **Botão "Girar"**, que sorteia símbolos para cada rolo.
- **Resultado automático**:
  - Se os 3 símbolos forem iguais → `WIN 🎉`
  - Caso contrário → `LOSER ❌`
- **Contador de jogadas**, mostrando quantas vezes o usuário clicou em "Girar".
- **Imagens personalizáveis**, permitindo substituir os símbolos por qualquer conjunto de ícones.
- Estrutura totalmente **local**, sem dependência de frameworks externos.

```bash

💡 Tecnologias Utilizadas
HTML5 – Estrutura da página e elementos do jogo.

CSS3 – Estilo visual, rolos, botões e layout responsivo.

JavaScript (Vanilla) – Lógica do sorteio de símbolos, animação de giro e verificação de resultado.

Imagens locais – Os símbolos dos rolos estão na pasta public/, podendo ser substituídos conforme a preferência do usuário.

🎯 Objetivos de Aprendizado
Este projeto permite praticar e entender:

Manipulação do DOM (Document Object Model) com JavaScript.

Uso de arrays, funções aleatórias e loops.

Controle de eventos com EventListener.

Estruturação de projetos front-end simples.

Criação de interfaces interativas e dinâmicas.

Boas práticas de organização de arquivos em projetos web.

🔧 Possíveis Evoluções
